v9 transport stability patch

- File status and existing job GET requests: up to 2 retries, within the original per-request time budget. Existing v8 output recovery is retained.
- Job creation POST is never automatically retried. If its outcome is uncertain, check Studio monitoring before any manual retry. The existing batch pause-on-error behavior is retained intentionally.
- 401/403/429 and other non-transient errors are not automatically retried. TLS certificate checks remain enabled. Persistent upstream outages still produce an error; this patch does not fix the provider server.
